New devices require approval. Verify the complete fingerprint in the local application's About panel before approving. Online means the authenticated reverse tunnel is connected and its local Web endpoint is ready. No passwords or MCP keys are uploaded.

From another PC, sign in here and choose Open device for the approved Online installation. The device address alone does not grant access. A compatible Windows machine host offers its Windows workspace chooser inside the device page; each selected profile keeps its own password and data. This is access to Anubis on that machine, not Windows screen sharing. The standalone Web demo is a separate installation.

Copy device URL copies only the nonsecret HTTPS address, not authorization. A different browser or incognito window must sign in to this administrator panel and use Open device again. If the selected app profile has a password, obtain its existing app-profile password from the profile owner; this is not a Windows/RDP password or the administrator token. A profile without an app password may open directly after browser authorization. This setting is not advertised by inventory, and this panel cannot retrieve, set or reset profile passwords. No SSH/RDP/VNC address, port or password is advertised by this inventory.

Windows accounts, SIDs, sessions and workspace availability are not advertised in this inventory. On compatible Windows machine hosts, Open device starts with the separate SYSTEM profile; explicitly select an available logged-on user inside that page for that user's data. MCP stays in its administrative workspace. Neither an online tunnel nor a temporary MCP grant proves a successful application login or protocol connection.
