# RDP, VNC и SPICE

Эти протоколы подключаются к уже работающей службе или гостевой VM. Установка Anubis сама по себе не открывает экран Windows и не разворачивает сервер.

| Протокол | Что подготовить |
| --- | --- |
| RDP | Разрешённый RDP-сервер, адрес/порт, учётную запись и серверную политику входа |
| VNC | Доступный VNC-сервер, его параметры аутентификации и защищённый маршрут |
| SPICE | Настроенный SPICE endpoint гостя либо корректный `.vv`-файл |

Создайте закладку нужного типа; стандартные порты RDP 3389 и VNC 5900 могут быть изменены администратором. Не публикуйте службы в Интернет только ради проверки. Не отключайте проверку сертификатов и не используйте незащищённый VNC в недоверенной сети.

В machine GUI внешние protocol URL и `.vv` требуют подтверждения целевого workspace. Файл подключения может содержать секреты и сроки действия; не прикладывайте его целиком к публичному issue.

SYSTEM/session 0 — контекст backend, не интерактивный экран вошедшего пользователя. Отображение рабочего стола зависит от сервера RDP/VNC, его сессии и прав. Наличие managed-билета не выдаёт права RDP.

SPICE-поддержка не гарантирует совместимость всех гостей и перенаправлений устройств; уточняйте версию клиента и сервера при обращении.
