# Windows account, SID, session и SYSTEM

Machine host разделяет службу, headless engine и интерактивный GUI. Используйте эти возможности только в совместимой установленной версии: [статус 5.7.3](Versions.md).

`NT AUTHORITY\SYSTEM`, SID `S-1-5-18`, session 0 — служебный контекст. Его профиль и закладки не равны профилю вошедшего пользователя. Session 0 не является Windows screen sharing.

Пользовательский workspace привязан к разрешённому SID и доступной logon/WTS-сессии. При выходе пользователя, смене сессии или политики нельзя незаметно подменять его SYSTEM. **Refresh** обновляет доступные контексты, но не выдаёт права и не сбрасывает пароль.

## Границы UAC

Повышение установщика не делает любой терминал административным. Путь приглашения PowerShell также не доказывает права процесса. Проверяйте account/SID/session выбранного workspace и разрешённую операцию.

Новая machine-установка не обязана разрешать пользовательские workers по умолчанию. Их разрешение — отдельное административное действие по native-контракту, а не автоматическое следствие входа Windows.

Native GUI соединяется с локальным broker и локальным workspace endpoint. В нём нет готового выбора удалённого устройства по UUID. Для другого ПК используйте managed Web либо прямую сетевую службу.

Перед внешней ссылкой/`.vv` machine GUI показывает **Open requested connection** с контекстом назначения. Не подтверждайте запрос, если учётная запись не соответствует намерению.
