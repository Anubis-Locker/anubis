# Установка и обновление

Выберите пакет своей ОС и архитектуры на [сайте загрузок](https://download.anubis.locker). Сверьте опубликованную версию и `SHA256SUMS` для конкретных байтов пакета. Наличие файла не подтверждает подпись издателя; отсутствие доверенной подписи нельзя исправлять отключением защиты ОС.

## Desktop

Windows, macOS и Linux используют разные пакеты. Перед обновлением сохраните работу, завершите передачи и подготовьте проверяемую резервную копию профиля. Установка клиента не включает SSH/RDP/VNC-сервер на целевой машине.

Для Windows x64 machine-установщика в частных исходниках предусмотрены per-machine установка и автоматическая SCM-служба. Нужен UAC; GUI остаётся процессом интерактивного пользователя. Portable/archive не создают machine-службу. Установщик после UAC работает без мастера и не запускает GUI; не переносите сюда старое обещание автоматического запуска.

В source-контракте `--console` включает диагностику. Не используйте непроверенный набор ключей или ручной перенос пользовательского профиля в SYSTEM. Обновление ждёт штатного закрытия приложения и может завершиться ошибкой; принудительное завершение чужих процессов недопустимо.

Полные ограничения, коды ошибок и миграция: [Windows installer](../WINDOWS-INSTALLER.md). Это контракт кандидата, не подтверждение публичной поставки 5.7.3.

## Web

Runnable-пакет и его CLI принадлежат отдельному [репозиторию anubis-web](https://github.com/Anubis-Locker/anubis-web). Используйте его актуальную инструкцию и явно выбранную версию из реестра `https://npm.anubis.locker/`; не выводите версию Web из номера Desktop. Не запускайте случайный скрипт из обсуждения.

На дату публичной проверки в [матрице версий](Versions.md) опубликован `anubis-web@5.6.12`. Для этой версии при Node.js 24 или новее:

```powershell
npm install -g anubis-web@5.6.12 --legacy-peer-deps --registry=https://npm.anubis.locker/
anubis-web
```

CLI создаёт отдельную приватную конфигурацию и сильные независимые Web credentials; существующая конфигурация сохраняется. Одобрение устройства не заменяет Web-вход. Не подставляйте `@5.7.3` только потому, что такой номер указан в частных исходниках приложения.

## Если обновление не удалось

Запишите версию, стадию и код ошибки. Сохранённые данные не удаляйте; повторная установка не равна восстановлению профиля. Ошибка старта установщика или отказ UAC — не успешное обновление.
