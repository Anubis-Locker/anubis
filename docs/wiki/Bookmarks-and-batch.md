# Закладки, группы и пакетная работа

Создавайте закладки через **New bookmark**, задавайте понятное имя и группируйте по назначению: например, тестовая среда и рабочая среда. Не помещайте секреты в название, описание или экспорт для обращения в поддержку.

**Quick connect** удобно для разового адреса; для повторяемой работы сохраните параметры в закладке. **Profiles** переиспользуют параметры подключения и не являются Windows account.

## Batch

Встроенный **batch-op** доступен через Widgets. Сначала выберите малую тестовую группу и проверьте список целей. Для массового ввода/quick commands убедитесь, в какие именно терминалы отправляется текст: фокус одной вкладки не гарантирует одиночную отправку при включённом групповом режиме.

Начинайте с read-only команды. Не отправляйте пароли общим вводом. Пакетная операция не даёт транзакции: ошибка одного соединения не откатывает уже выполненные команды на других серверах.

## Перед импортом и переносом

Сохраните резервную копию, проверьте состав экспорта и импортируйте сначала в изолированный профиль. Секреты могут зависеть от OS keychain; копия БД не гарантирует работоспособность на другой машине.
