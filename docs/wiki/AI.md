# AI-интеграция без лишних обещаний

Anubis содержит AI-интерфейс, настройки провайдера и сценарии помощи с командами/закладками. Наличие кнопки **AI Agents** не доказывает, что серверная модель настроена.

В исходниках сервис `services/ai-stub.js` отвечает текстом «Заглушка». Endpoint бренда `https://ai.anubis.locker/api/ai` и модель по умолчанию не являются гарантией работающего AI-провайдера.

Администратор задаёт endpoint через brand/admin policy. Если он заблокирован, пользовательские пресеты не должны его обходить. Для собственной модели администратор согласует совместимый API, модель, аутентификацию, TLS и обработку данных. Не храните ключ в `brand.config.js`: этот объект попадает в renderer.

Перед отправкой удалите пароли, ключи, содержимое конфиденциальных файлов и внутренние адреса. Ответ модели — рекомендация, не разрешение выполнить команду. Проверяйте назначение хоста, права и побочные эффекты.

AI-чат и внешний MCP-клиент — разные интеграции. Разрешение читать чат не равнозначно праву выполнять команды через MCP. PRO **Automation** и **Browser Control** остаются заглушками и не добавляют агенту удалённый браузер.
