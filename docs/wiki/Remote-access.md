# Как выбрать способ удалённой работы

Для подключения **к службе сервера** создайте SSH/RDP/VNC-закладку с адресом этой службы. Для открытия **профиля Anubis на одобренном ПК** используйте Managed devices → Open device. Для изображения **экрана Windows** нужен RDP либо VNC.

Полная пошаговая инструкция и разбор повторного входа: [REMOTE-ACCESS.md](../REMOTE-ACCESS.md). Она является основным руководством по этому сценарию; здесь не вводится альтернативный способ обхода входа.

## Проверка перед началом

- Выбрана правильная задача: терминал, профиль приложения или экран.
- Устройство одобрено и online; одного heartbeat недостаточно.
- Известен нужный Windows account/SID/session, а не только имя ПК.
- Получен существующий пароль приложения у владельца профиля, если он установлен.
- Версия клиента совместима с host; [частная 5.7.3](Versions.md) не считается уже установленной.

Скопированный URL устройства не авторизует другой браузер. Windows-пароль, management-токен, MCP-токен и пароль профиля невзаимозаменяемы.

HTTP/HTTPS-сайт внутри Web использует браузер и сеть оператора, включая CSP, X-Frame-Options и mixed-content ограничения. Это не тест доступности сайта с удалённой машины.
