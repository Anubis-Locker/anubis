# Диагностика без потери данных

Сначала укажите режим, версию и ожидаемую операцию. «Не подключается» может относиться к разным уровням.

| Симптом | Что проверить |
| --- | --- |
| Устройство offline | Запущен ли совместимый host, готов ли Web-компонент, есть ли исходящий маршрут |
| Устройство approved, но профиль не открыт | Browser login и отдельный пароль приложения |
| Нет нужного пользователя в workspace | Разрешён ли SID, доступна ли logon-сессия, результат Refresh |
| Видны пустые/другие закладки | Выбран ли нужный профиль, а не SYSTEM |
| Web-вкладка сайта пуста | CSP/XFO, mixed content и сеть браузера оператора; попробовать Open |
| Вход постоянно сбрасывается | Logout/revoke/смена пароля, срок сессии, рестарт gateway, затем сетевые ошибки |
| MCP недоступен | Готовность виджета, правильный endpoint/transport, токен и срок гранта |
| Терминал виден, но команда не работает | Учётная запись, права, доступность цели и реальный код завершения |
| Обновление Windows не состоялось | Отказ UAC, код установщика, незакрытый GUI, совместимость пакета |

Тридцать секунд входного билета не объясняют бесконечные повторные логины. **Browser authorized** не подтверждает работоспособность терминала/RDP/VNC. Проверка PowerShell должна устанавливать реальный контекст, не делать вывод по пути приглашения.

Для публичного обращения достаточно версии/ОС, режима, времени с часовым поясом, точных шагов, ожидаемого и фактического результата, HTTP-статуса или кода ошибки. Имена, адреса и account/SID/session замените согласованными обезличенными обозначениями.

Удалите cookies, токены, пароли, ключи, секретные URL, `.vv`-содержимое и приватные пути. Полный HAR может содержать секреты; не публикуйте его без отдельной очистки.

Не «исправляйте» проблему удалением профиля, ключей, identity или отключением auth/TLS. Если ошибка касается шифрования, остановитесь и сохраните исходные данные.
