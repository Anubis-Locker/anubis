# Первое подключение

Начните с сервера, к которому у вас уже есть разрешённый сетевой маршрут и учётная запись. Anubis — клиент: он не включает удалённые службы и не выдаёт права доступа.

1. Откройте Desktop, затем меню приложения → **New bookmark**.
2. Выберите SSH, укажите разрешённое DNS-имя, порт и имя пользователя.
3. Настройте пароль или ключ через поля формы, сохраните закладку.
4. При первом входе независимо сверьте SSH fingerprint. При несовпадении остановитесь и выясните причину.
5. Откройте терминал; проверьте, что команда выполняется на ожидаемом сервере и под ожидаемой учётной записью.

**Quick connect** принимает строку подключения, например:

```text
ssh://operator@server.example:22
rdp://operator@server.example:3389
vnc://server.example:5900
```

Пароли в URL не указывайте. Для RDP/VNC выберите соответствующий протокол и используйте учётные данные именно его сервера.

В Windows machine GUI запрос от внешней ссылки дополнительно проходит **Open requested connection** с подтверждением Windows account/SID/session. Если профиль защищён паролем приложения, сначала нужен этот пароль.

Нужен интерфейс Anubis на другом ПК, а не прямое соединение? Используйте [managed access](Managed-access.md).
