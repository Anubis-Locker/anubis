# 🤝 Сообщество Anubis

В [Discussions](https://github.com/Anubis-Locker/anubis/discussions) включены шесть стандартных категорий GitHub. Опубликованы четыре оригинальных материала от сопровождающих; остальные сценарии остаются редакционными заготовками, а не сообщениями вымышленных участников.

Открытие форума не означает выпуск нового runtime. Кандидат 5.7.3 не должен описываться как уже установленный или прошедший живую приёмку.

## Категории

| Категория | Формат GitHub | Для чего | Стартовая тема |
| --- | --- | --- | --- |
| [Announcements](https://github.com/Anubis-Locker/anubis/discussions/categories/announcements) — 📣 Объявления | Announcements | Проверенные релизы, изменения и ограничения; пишет команда | Что подтверждено для текущего релиза |
| [Q&A](https://github.com/Anubis-Locker/anubis/discussions/categories/q-a) — ❓ Вопросы и ответы | Q&A | Конкретные вопросы с отмеченным ответом | Как выбрать Desktop, Web или managed |
| [Ideas](https://github.com/Anubis-Locker/anubis/discussions/categories/ideas) — 💡 Идеи | Open-ended discussion | Проблема пользователя, сценарий и критерий пользы | Как улучшить выбор workspace без путаницы |
| [Show and tell](https://github.com/Anubis-Locker/anubis/discussions/categories/show-and-tell) — 🧭 Практика | Open-ended discussion | Проверенные инструкции и разборы | Безопасное первое SSH-подключение |
| [General](https://github.com/Anubis-Locker/anubis/discussions/categories/general) — 💬 Общение | Open-ended discussion | Знакомство, рабочие привычки, обратная связь | Какие задачи вы решаете клиентом |
| [Polls](https://github.com/Anubis-Locker/anubis/discussions/categories/polls) — 📊 Опросы | Polls | Только решения, по которым команда готова действовать | Какой раздел Wiki уточнить первым |

Q&A не заменяет bug tracker. Баг с воспроизводимыми шагами переносится в issue со ссылкой на обсуждение без дублирования секретных вложений. Уязвимости направляются в приватный канал.

## Темы и маркировка

Для заголовков/поиска полезны темы `desktop`, `web`, `managed-access`, `windows-workspace`, `ssh-sftp`, `remote-desktop`, `mcp`, `sync`, `documentation`. Это предложение тематизации, не обещание отдельной функции «тегов» Discussions.

Публиковать от команды: подпись **FAQ сопровождающих** либо **Сценарий для обсуждения**. В Q&A ответ отмечается после проверки, не автоматически ради статистики.

## Работа с ответами

Сначала уточнять режим и версию, затем давать безопасный следующий шаг. Для непроверенной функции писать «не подтверждено», для PRO-заглушки — «не реализовано». Не обещать срок исправления без решения команды.

Один полезный материал лучше серии пустых сообщений. Опубликованы [приветствие](https://github.com/Anubis-Locker/anubis/discussions/6), [FAQ о режимах](https://github.com/Anubis-Locker/anubis/discussions/7), [FAQ о Web-вкладках](https://github.com/Anubis-Locker/anubis/discussions/8) и [первое SSH-подключение](https://github.com/Anubis-Locker/anubis/discussions/9). Остальные сценарии публикуются по мере готовности. Не создавать подставные аккаунты и не изображать пользовательский спрос.
